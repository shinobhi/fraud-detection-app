# Fraud Event Analyzer

A small fraud-triage application that combines deterministic business rules with
an AI-assisted risk assessment. Paste a JSON event into the browser interface to
receive a structured risk rating, incident summary, detected signals, and
recommended follow-up actions.

**Live application:** [fraud-detection-app.cilindra.workers.dev](https://fraud-detection-app.cilindra.workers.dev/)

## How it works

1. Cloudflare serves the frontend from `public/` as static assets.
2. The browser validates the pasted JSON and sends it to `POST /analyze`.
3. `src/fraud_rules.py` evaluates the event using deterministic rules.
4. The event and locally derived signals are sent to Workers AI using
   `@cf/meta/llama-3.3-70b-instruct-fp8-fast`.
5. The model provides a non-deterministic assessment constrained by a JSON
   Schema, so every successful response contains `risk`, `summary`, `signals`,
   and `recommended_actions`.

The deterministic layer produces repeatable signals from explicit thresholds:

- The IP country differs from the account country.
- The card country differs from the account country.
- More than four prior accounts are associated with the IP address.
- More than four payment attempts were made from the card in the last hour.

The non-deterministic layer uses the full event and those signals to assess
context, assign a `low`, `medium`, or `high` risk level, summarize the incident,
and recommend investigation or mitigation steps. It is instructed not to claim
that fraud has definitively occurred or invent unsupported facts.

## Architecture

```text
Browser UI (public/)
        |
        | POST /analyze
        v
Python Worker (src/entry.py)
        |
        +-- deterministic rules (src/fraud_rules.py)
        |
        +-- structured assessment (Cloudflare Workers AI)
        |
        v
JSON response
```

## Example

The application opens with this event:

```json
{
  "message": "Fraud event received",
  "event": {
    "email": "jsmith+promo17@gmail.com",
    "country": "US",
    "ip_country": "RO",
    "card_country": "US",
    "promo_code": "FREE30",
    "prior_accounts_from_ip": 8,
    "payment_attempts_last_hour": 5
  }
}
```

A representative response is:

```json
{
  "risk": "high",
  "summary": "The event contains multiple signals that warrant additional verification, including a country mismatch and elevated account and payment activity.",
  "signals": [
    "IP country (RO) does not match account country (US).",
    "IP address is associated with 8 prior accounts, which exceeds the threshold of 4.",
    "Card has 5 purchase attempts in the last hour, which exceeds the threshold of 4."
  ],
  "recommended_actions": [
    "Temporarily hold the transaction for manual review.",
    "Verify the account holder's identity and recent activity.",
    "Review the related accounts and payment attempts for coordinated abuse."
  ]
}
```

Because the final assessment is generated by an AI model, its wording and
recommendations may vary while retaining the required response structure.

## Run locally

Install [Node.js](https://nodejs.org/) and
[`uv`](https://docs.astral.sh/uv/), then run:

```powershell
npm install
uv sync
uv run pywrangler dev
```

Open the local URL printed by Wrangler, normally `http://localhost:8787`.

## Deploy

After authenticating with Cloudflare, deploy the Worker and its static assets:

```powershell
npx wrangler login
uv run pywrangler deploy
```
